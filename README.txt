Car Specs Explorer Ultra (PWA)
=================================
Nyheter:
- WLTP (heuristiskt): hämtas när möjligt från Wikipedia (infobox/tabeller). Fallback till US EPA MPG som referens.
- Galleri: bilder från Wikimedia Commons/Wikipedia.
- Liknande modeller, favoriter, jämförelse, delningslänk, export JSON, utskrift.
- Car.info-lik layout med KPI-kort och sektionstabeller.

Publicera/uppdatera på GitHub Pages
-----------------------------------
1) Gå till ditt repo (t.ex. car-specs-explorer).
2) Klicka **Add file → Upload files**.
3) Dra in/ersätt: index.html, manifest.webmanifest, sw.js, README.txt från denna zip.
4) Scrolla → **Commit changes**.
5) Sidan auto-uppdateras. Ladda om din Pages-URL och installera igen om du vill.

Sekretess
---------
Endast öppna datasätt. Ingen person-/regnr-data.
